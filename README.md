# backplate-studio — 단행본 장별HTML 트레일러 제작 에이전트

**단행본 원고 한 장(HTML)을 넣으면 16:9 영상 한 편이 나옵니다.**
그림·음성·자막·모션까지 한 서버에서 끝나고, 산출물은 `mp4` 한 개입니다.

이 레포가 다른 점은 한 줄입니다 — **글자를 그림에 굽지 않습니다.**
그림은 배경만 만들고 글자는 화면이 **진짜 텍스트로 얹습니다.** 그래서 한글이
안 깨지고, 모션이 DOM 요소를 직접 움직이므로 마스크 상자를 지정할 일이 없으며,
글이 그림을 가리면 **그림을 다시 굽지 않고** 화면에서 끌어 옮기면 됩니다.

18장짜리 책 한 권을 이 도구로 냈습니다 — 5시간 29분, 장당 평균 36분이 걸렸습니다.

```
setup.bat        (mac·linux: ./setup.sh)    처음 한 번
run.bat          (mac·linux: ./run.sh)      → http://localhost:5178
```

**API 키가 필요 없습니다.** ChatGPT 구독 로그인을 그대로 씁니다.
터미널에서 `codex login` 을 한 번 실행해 두면 됩니다 — **로그인은 그거 하나**이고
대본·목차·그림 지시문·비전·그림이 전부 그것으로 나갑니다.

## 결과물

```
11_완성/<slug>-motion.mp4        완성 영상. 모션 + 합본 −16 LUFS 까지 한 번에
11_완성/<slug>-img.html          같은 내용, 파일 하나. 외부 참조 0. 메일로 보낼 수 있음
08_자막/NNN.srt                  사이드카 자막(번인하지 않습니다)
```

**mp4 를 만듭니다.** 예전에는 "이 페이지를 화면녹화하세요" 였습니다. 지금은
`s12h-hyper` 가 장마다 화면을 찍어 내레이션 길이만큼 이어 붙이고, **글자가 떠오르는
모션과 −16 LUFS 정규화까지 한 번에** 합니다. 글자가 DOM 이라 GSAP 이 직접 움직입니다
— 그림에서 상자를 되찾을 일이 없습니다.

산출물은 **앱 폴더 밖 형제 폴더**에 쌓입니다:

```
…/backplate-studio/          앱 (git)
…/showcase-out-260918/       산출물  ← SHOWCASE_WORKSPACE 로 재지정 가능
```

앱을 지우고 다시 받아도 만들어 둔 영상이 그대로 남습니다. 렌더 임시 폴더(`_render-tmp/`)도
여기 생깁니다 — 산출물과 같은 드라이브여야 합니다.

## 무엇을 어떤 차례로

**괄호 안은 앱이 하는 일**입니다. 괄호 밖이 사람이 보고 정하는 자리입니다.

원고를 올리고 목차를 확정한 다음, 왼쪽 메뉴를 **위에서 아래로** 훑으면 끝납니다.

```
1  원고 HTML → 「이미지 JSON 만들기」     (그림 지시문)      ← 구독 할당량
2  원고 HTML → 「그림 굽기」              (서버 안에서 굽습니다) ← 구독 할당량
3  라벨 자리  → 글 고치고 끌어 옮기기      모눈 2.5% 에 달라붙습니다
4  덱       → 「음성/자막 굽기」          끝나면 장별로 들립니다
5  말하는 순간 → 라벨이 몇 번째 문장에서 뜰지   ★ 음성이 있어야 보입니다
6  영상 렌더링 → 「(전체) 영상 렌더」       점검을 보고 굽습니다
```

**예전에는 17단계였습니다.** 글자를 그림에 굽지 않게 되면서 다섯 단계가 통째로
사라졌습니다 — 상자 자리 찾기 · 마스크 지정기 · 마우스 마스킹 · JSON 넣기 · 차례 잡기.
전부 「글자가 픽셀 안에 있으니 되찾아야 한다」는 한 뿌리였습니다.

그림 받기도 창을 옮겨 다닐 일이 없어졌습니다 — 이미지 스튜디오가 이 서버 안에
들어와 있고, 코덱스 로그인은 **워크스페이스 화면**에서 바꿉니다(유료 계정 둘을
번갈아 쓸 수 있습니다).

걸음마다 어디를 누르는지는 **[docs/01-매뉴얼.md](docs/01-매뉴얼.md)** 에 있습니다.

## 필요한 것

| | 없으면 |
|---|---|
| Python 3.10+ | 안 돕니다 |
| `codex` CLI + `codex login` | **대본·목차·지시문·비전·그림이 전부** 안 돕니다 |
| ffmpeg | 프레임 추출·영상 변환이 안 됩니다 |
| `gh` CLI | 레포 수집이 안 됩니다 (영상만으로도 덱은 나옵니다) |
| 슈퍼토닉3 가중치(`assets/`, 396MB) | 음성이 안 나옵니다. 덱·자막은 전부 나옵니다 |
| **디스크 여유** | 영상이 안 나옵니다 — 아래 |

`setup.bat` 이 `tools/wire_tts.py` 로 `showcase.config.local.json` 을 채웁니다.
엔진 코드는 **이 레포 안 `tts/`** 에 있고(예전엔 형제 폴더의 `voicewright/`),
밖에서 받아야 하는 것은 가중치와 엔진 venv 둘뿐입니다. 막히면 진단이 이름으로
알려 줍니다:

```
.venv-app\Scripts\python tools\doctor.py
```

성우 파일을 `07_음성/005.wav` 처럼 번호로 넣어 두면 **그 장은 합성하지 않습니다.**

### 디스크 — 영상 길이에 비례합니다

굽개(HyperFrames)가 **모든 프레임을 파일로 찍어 놓고** 이어 붙입니다. 실측하면
1920×1080 jpeg 한 장이 **468KB**, 30fps 라 **분당 0.81GB** 입니다.

| 길이 | 프레임 | 굽는 동안 필요한 여유 |
|---|---|---|
| 20분 | 36,000 | 약 17GB |
| 1시간 | 108,000 | 약 49GB |
| 2시간 | 216,000 | 약 98GB |

**산출물 폴더와 같은 드라이브**에 쌓입니다(`<산출물>/_render-tmp/`). 예전에는
`os.tmpdir()` 를 따라 C 로 갔고, C 가 꽉 차 `ENOSPC` 로 렌더가 통째로 터졌습니다.
정상 종료하면 스스로 지우고, 터져서 남은 것은 다음 렌더가 시작할 때 치웁니다.

긴 편은 **장마다 굽고 `ffmpeg -c copy` 로 이어붙이는 것**이 쌉니다 — 제일 긴 장
하나치만 있으면 됩니다. **여러 장을 동시에 굽지 마세요.** 필요량이 그대로 곱해집니다.

## 하지 않는 것

- **글자를 그림에 굽지 않습니다.** 그림은 배경만 만들고 글자는 화면이 진짜 텍스트로
  얹습니다. 한글이 안 깨지고, 모션이 DOM 을 직접 움직입니다. 글이 그림을 가리면
  **그림을 다시 굽지 않고** 「라벨 자리」에서 끌어 옮깁니다.
- **LAN 공유를 하지 않습니다.** 이 앱은 호스트의 ChatGPT 구독으로 돕니다.
- **API 키를 쓰지 않습니다.** `~/.codex/auth.json` 의 OAuth 토큰만 씁니다.
- **모델이 파일을 직접 만지지 않습니다.** 툴 없이 브리프만 보고 답합니다 —
  레포는 호스트가 clone 하고, 그 요약만 프롬프트에 실립니다.
