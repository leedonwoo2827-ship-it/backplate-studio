# 쪽지 — 바탕이 간혹 검게 나오는 건, 문장 **순서** 때문입니다

보내는 곳: 이미지 생성 쪽(`260628-로컬이미지_앞에프롬프트필더`)
대상 파일: `pipeline/s3a_imgprompt.py` 190~204행
겪은 일: 제20장 32장 중 **006 · 010** 두 장이 검은 배경으로 나와 남색 제목·슬레이트 글자가 묻혔습니다.
(나머지 30장은 완벽했습니다. 늘 나는 게 아니라 간혹 나는 게 이 문제의 성격입니다.)

## 이미 고치려 하신 걸 봤습니다

193~197행에 이렇게 적혀 있더군요.

```python
# ★ **바탕을 밝게 못박는다.** 색/톤에 강조색만 적고 바탕을 안 적었더니
#   모델이 검정 판으로 가서 제목이 배경에 묻혔다(2026-08-16 실측: 003.png).
tone = (tone + " · 바탕은 반드시 **밝은 아이보리(#F6F1E8)**. "
        "어두운 배경·검정 판·야간 장면으로 그리지 마라 — 글자가 묻힌다")
```

진단은 정확하셨는데, **붙인 자리가 뒤라서** 아직 샙니다. 완성된 색/톤 줄이 이렇게 됩니다.

```
색/톤: 진한 파랑(#1F4E79)과 밝은 파랑(#9DC3E6) 중심, 슬레이트(#334155) 글자, … · 바탕은 반드시 **밝은 아이보리(#F6F1E8)**. 어두운 배경·검정 판·야간 장면으로 그리지 마라
```

이미지 모델은 이 줄을 앞에서부터 읽습니다. **"진한 파랑 중심"**을 먼저 만나면 그 색을 화면의 지배색 = 배경으로 잡아 버리고, 그다음 `·` 뒤에 오는 "바탕은 밝은 아이보리"는 이미 정해진 배경을 뒤집지 못하고 흘러갑니다. 그래서 대부분은 맞게 나오다가 가끔 뒤집히는, 딱 지금 같은 산발적 실패가 납니다.

한 가지 더 — `"진한 파랑과 밝은 파랑 **중심**"`이라는 말 자체가 "이 색으로 화면을 채우라"로 읽힙니다. 실제로 원하시는 건 *글자와 강조에* 그 파랑을 쓰라는 것이지요.

## 이렇게 바꿔 주시면 됩니다

핵심은 **바탕색을 강조색보다 먼저 적는 것** 하나입니다.

```python
# 바탕색은 강조색보다 앞에 적는다. 뒤에 붙이면 모델이 앞서 읽은
# 강조색으로 이미 배경을 칠해 버려서 뒤집히지 않는다.
tone = _one(tone, 220) or (
    f"글자와 강조에 진한 파랑({img['accent_a']})과 밝은 파랑({img['accent_b']}), "
    "본문 글자는 슬레이트(#334155), 플랫 벡터에 은은한 입체감")

lines = [
    f"바탕: 화면 전체를 밝은 아이보리({img['bg']}) 단색으로 고르게 칠한다 — "
    "네 귀퉁이와 가장자리까지 같은 밝기다. 어두운 배경·검정 판·야간 장면·"
    "비네팅(가장자리 어둡게)·어두운 그라데이션·발광(글로우) 금지 — 글자가 묻힌다. "
    "진한 파랑은 글자와 강조에만 쓰고 배경에는 쓰지 않는다",
    f"배경: {_one(background, 220)}",
    f"구도: {_one(layout, 260)}",
    f"색/톤: {tone}",
    ...
]
```

바뀌는 건 셋입니다.

1. **`바탕:` 을 독립된 첫 줄로** 올립니다. 색/톤 줄에 얹지 않습니다.
2. 기본 tone 의 `"진한 파랑…중심"` → **`"글자와 강조에 진한 파랑…"`**. "중심"이라는 낱말을 뺍니다.
3. 금지 목록에 **비네팅·어두운 그라데이션·발광**을 넣습니다. 검은 배경만 막으면 모델이 "가장자리만 어둡게"나 "어두운 데서 빛나는" 쪽으로 빠져나가는데, 결과는 똑같이 글자가 묻힙니다. 실제로 006 이 그 경우였습니다.

`negative` 필드에도 같이 넣어 주시면 좋습니다.

```
vignette, dark vignette, darkened edges, dark corners, dark gradient,
glow, bloom, neon glow, backlit, spotlight on dark, inverted color scheme,
light text on dark background
```

## 이쪽에서도 한 겹 받쳐 뒀습니다

`260628-로컬이미지_앞에프롬프트필더/services/batch_jobs.py` 의 `compose_prompt()` 에
**배경 대비 가드**를 넣었습니다. 프롬프트에 배경색이 명시돼 있으면(`배경`/`바탕` + 헥스값)
그 지시를 프롬프트 맨 앞으로 한 번 더 올려 줍니다. 특정 색을 강요하지 않으므로
어두운 덱을 만드실 때도 그대로 쓰실 수 있습니다.

다만 이건 **그물이지 해결책이 아닙니다.** 프롬프트 자체가 바른 순서로 오는 게 제일 깨끗하니
위 세 가지는 그대로 반영해 주시면 좋겠습니다.
