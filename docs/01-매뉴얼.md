# 매뉴얼 — 한 챕터를 끝까지 만드는 여덟 걸음

원고를 받아 유튜브에 올릴 영상까지. **괄호 안은 앱이 하는 일**이다 — 누르고
기다리면 된다. 괄호 밖이 사람이 눈으로 보고 정하는 자리다.

```
1  원고 HTML 넣기            → (구조 읽기)  ★ 길이를 여기서 확인한다
2  목차 — 순서·제목 확정                    표지·마무리는 「+썸네일」로
3  (그림 지시문)                          → 09_이미지 에 JSON 두 개
4  (이미지·썸네일 JSON 만들기)
   4.2  다른 에이전트에서 그림 받기          번호로 09_이미지 에 넣는다
5  (덱 전체 · 자막 대본 생성)              화면에 보이는 원문
   5.2  (발음 대본 생성)                   그 자막을 소리 나는 대로
6  (덱 전체 · 음성/자막 굽기)
7  (영상 렌더링)
   7.2  장별로 듣기 — 발음 고치고 OK
   7.3  마스킹 — 지정기 → 상자 → 차례 잡기
   7.4  (음성 빼고 굽기 → 영상 다시 렌더링)  ★ 발음을 고쳤을 때만
8  (모션 전체 굽기)                        유튜브 글 올리고 최종 청취
```

## 1 · 원고 HTML 넣기

좌측 메뉴 **수정 — 유형 → + 원고 HTML**

> 📷 _캡처 자리 — 원고 HTML 화면_

원고의 `data-say` 가 **그대로 강의 내레이션이 된다.** 넣는 순간 앱이 길이를
말한다.

```
원고 대본 32장 · 6,100자 → 약 18.6분
```

★ **여기가 되돌리기 가장 싼 자리다.** 짧으면 지금 되돌린다. 그림·음성·영상을
만든 뒤에 알면 전부 다시 해야 한다 — 20장이 6분으로 나와 실제로 되돌렸다.

원고 맨 위에 `<!-- 20장 · 목표 15~20분 -->` 이 있으면 목표와 견준다.
분량 기준은 [02-원고-보내실-때.md](02-원고-보내실-때.md).

| 목표 | 공백 뺀 `data-say` 합계 |
|---|---|
| 15분 | 약 5,000자 |
| 20분 | 약 6,600자 |

## 덱 상단 — 단추 지도

5번부터는 전부 여기다. 좌측 메뉴 **덱**.

> 📷 _캡처 자리 — 덱 상단 단추 줄 전체_

```
[슬라이드 보기] [대본 인쇄본]  ④ 배경음악  ⑤ 자막 대본 생성
```

## 5 · 자막 대본 생성

덱 → **⑤ (전체) 자막 대본 생성**

화면에 보이는 원문을 만든다. **원고가 대본을 들고 왔으면 그대로 쓴다 —
공짜다.** Claude 는 원고가 없는 장에서만 부른다.

### 5.2 · 발음 대본 생성

덱 → **⑥ (전체) 발음 대본 생성**  ·  몇 초 · 공짜

★ **왜 갈랐나.** 손이 가는 순서가 「자막을 읽고 고친다 → 그 자막대로 발음을
만든다」이기 때문이다. 한 번에 만들면 자막을 고쳐도 발음은 옛 자막에서 나온
채로 남는다 — 20장에서 실제로 그랬다.

Claude 를 안 부르는 결정론이라 **자막을 고칠 때마다 다시 눌러도 손해가 없다.**
네 가지를 한다.

```
괄호   국내총생산(GDP)은  →  국내총생산은
어미   늘었다             →  늘었습니다        (이미 높임이면 안 건드림)
숫자   1929년 1,040억     →  천구백이십구 년 천사십 억
기호   250%               →  이백오십 퍼센트
```

손으로 고쳐 둔 발음이 있으면 **몇 장이 덮이는지 먼저 말하고 묻는다.**
자막은 건드리지 않는다 — 그것이 이 변환의 재료다.

★ **이미 장별로 손보기 시작했으면 누르지 마라.** 그 손질이 다 덮인다.
⑥은 굽기 전에 한 번 누르는 단추다.

원고가 `data-read` 를 실어 보내도 쓰지 않는다. 그쪽 발음은 길이를 재려고 만든
것이라 규칙이 다를 수 있고, 출처가 둘이면 어느 쪽이 소리로 나갔는지 알 수 없다.

## 7 · 영상 렌더링

좌측 메뉴 **영상 렌더링** → **(전체) 영상 렌더**

> 📷 _캡처 자리 — 영상 렌더링 화면_

`11_완성/<slug>.mp4` 가 나온다.

★ **듣기·마스킹보다 렌더링이 먼저인 이유** — 마스킹이 쓰는 스틸이 mp4 에서

(`pipeline/s12_video.py:149`). 영상이 없으면 상자를 얹을 그림이 없다.

### 7.2 · 장별로 듣기 — 발음 고치고 OK

덱 → 상단의 **장 번호 탭**(`전체 · 1 · 2 · … · 34`)

> 📷 _캡처 자리 — 장별 화면 한 판_

```
자막 (화면에 보이는 원문)   │  발음 (TTS 입력 · 실제로 읽는 텍스트)
                           │  [✦ 숫자를 소리대로]
음성  ▶ ━━━━━━━━━━  [✦ 자막에서 발음 만들기] [↻ 발음대로 다시 합성]
```

| 단추 | 무엇 |
|---|---|
| 자막에서 발음 만들기 | 이 장의 자막에서 발음을 다시 만든다. ⑥과 **같은 규칙** |
| 숫자를 소리대로 | 발음 칸의 숫자만. `1960년대` → `천구백육십 년대` |
| 발음대로 다시 합성 | **그 장만** 다시 만든다. 전체를 안 돌린다 |

**순서를 지켜라 — 손질이 마지막이다.**

```
1  [자막에서 발음 만들기]    기계가 할 것 — 괄호·어미·숫자·퍼센트
2  손으로 소리 고치기         대가 → 대까 같은 것
3  [발음대로 다시 합성]       듣기
```

반대로 하면 1번이 2번을 덮는다.

#### 발음 칸은 「소리 나는 대로 적는 자리」다

맞춤법을 지키는 자리가 아니다. 자막은 원문 그대로 두고, 여기에는 소리 나는
대로 적는다 — 그러라고 칸을 둘로 나눠 놓았다. 맞춤법 검사도 꺼 두었다.

```
자막   실질 GDP 는 2.0%  늘었습니다        ← 화면에 박히는 글
발음   실찔 지디피는 이 쩜 영 퍼센트 늘었습니다   ← 소리 나는 대로
```

★ **된소리는 손으로 적는다.** 방향이 한쪽으로만 열려 있다.

```
원가 → 원까    적어서 얻는 것.  된다
센다 → 쎈다    막아야 하는 것.  철자로는 못 막는다
```

TTS 가 제멋대로 된소리로 읽는 것은 끄는 스위치가 없다. 모델이 배운 습관이라
규칙이 아니다. **말을 바꾸는 수밖에 없다** — 20장에서는 「최종재만 센다는」을
「최종재만 셈하는 것이라는」으로 바꿨다.

#### 숫자가 몰린 문장은 씹힌다

한 문장에 숫자가 다섯이면 모델이 끝까지 못 간다. **발음 칸에서 문장을 끊어라.**
모델은 문장 끝에서 숨을 고른다.

```
지금   명목 GDP는 천구백이십구 년 천사십 억 달러에서 천구백삼십삼 년
       오백육십 억 달러로 사십육 퍼센트 줄었습니다.

끊어   명목 GDP는 천구백이십구 년에 천사십 억 달러였습니다.
       그것이 천구백삼십삼 년에 오백육십 억 달러로, 사십육 퍼센트 줄었습니다.
```

마침표가 빠진 곳도 같은 증상을 낸다 — 문장이 안 끝나면 이어 붙여 읽는다.

### 7.3 · 마스킹 — 지정기 → 상자 → 차례 잡기

같은 장별 화면, **음성 아래**.

영상을 갓 구웠으면 노란 줄이 먼저 뜬다.

> 📷 _캡처 자리 — 노란 「지정기 만들고 열기」 줄_

```
┌────────────────────────────────────────────────────────────┐
│ 마스킹을 하려면 먼저 지정기를 만드세요    [⧉ 지정기 만들고 열기] │
│ 영상에서 장마다 스틸을 뽑고 글자 자리를 상자로 찍어 둡니다      │
└────────────────────────────────────────────────────────────┘
```

**누르면 1~2분 걸린다.** 영상을 훑어 장마다 스틸을 뽑고, 기본 상자를 얹은
지정기 HTML 을 만들어 새 창으로 연다. **한 번만 하면 된다.**

```
11_완성/_<slug>-stills/s00.png …        스틸. 1920×1080
11_완성/<slug>-마스크지정기.html         지정기
```

끝나고 덱을 새로고침하면 그 줄 대신 **스토리보드**가 뜬다.

> 📷 _캡처 자리 — 스토리보드 (스틸 + 상자 + 단추 줄)_

```
스토리보드 — 말하는 차례와 글자 뜨는 차례       0 / 32 정리됨
상자 6개 · 문장 6개 · ⚠ 시각 없는 상자 6개

[⧉ 지정기 열기] [⇧ zones.json 넣기] [◎ 대본에 맞춰 차례 잡기] [전체]
[시간 자동 채우기]                              [정리됨 · 저장]
```

| 단추 | 무엇 | 주의 |
|---|---|---|
| 지정기 열기 | 있는 지정기를 연다. 여러 장 상자를 한꺼번에 찍을 때 빠르다 | — |
| zones.json 넣기 | 지정기에서 내려받은 파일을 넣는다 | **전체 장이 통째로 갈린다** |
| 대본에 맞춰 차례 잡기 | 상자 안 글자를 읽어 시각을 넣는다. **이 장만** | $0.1 |
| 전체 | 같은 일을 **모든 장에** | 몇 분 · $2~3 |
| 시간 자동 채우기 | 자막 시각으로 기계적으로 나눈다 | 차례는 안 봄 |
| 정리됨 · 저장 | 이 장 확정 → 다음 장으로 | — |

#### 도는 순서

```
1  [지정기 만들고 열기]         한 번만. 1~2분
2  새 창에서 상자 다듬기
3  [zones.json 내려받기]        새 창 안에 있다
4  덱으로 돌아와 [zones.json 넣기]
5  [대본에 맞춰 차례 잡기] → [전체]     몇 분 · $2~3
6  장을 훑으며 이상한 줄만 고친다
7  [정리됨 · 저장] → 다음 장
```

★ **5번은 상자 자리를 다 다듬은 뒤에 누른다.** 나중에 상자를 더하거나 지우면
그 장은 차례를 다시 잡아야 한다.

★ **상자 차례는 화면 위치가 아니라 말하는 차례다.** 19장은 31장 중 25장이
상자를 좌우로 두어, 위→아래 정렬로는 차례가 정해지지 않았다. 그래서 앱이
상자 안 글자를 오려 읽고 대본과 짝짓는다. 좌표만으로는 알 수 없다.

★ **시각이 비면 위에서 아래로 0.4초 간격으로 떠 버린다.** 40초짜리 장의 글이
앞 2.4초에 다 뜬다. `⚠ 시각 없는 상자` 가 0 이 되어야 한다.

★ 저장은 **장 하나씩** 간다. 모션 화면의 「zones.json 불러오기」는 파일을
통째로 갈아 끼운다 — 2026-08-16 에 그렇게 시각 186개가 날아갔다.

### 7.4 · 발음을 고쳤으면 다시 굽는다

```
발음을 고치고 [발음대로 다시 합성] 까지 눌렀다   →  덱 [↻ 음성 빼고 굽기]
발음만 고치고 합성은 안 눌렀다                  →  덱 ⑦ 음성/자막 굽기
```

**「음성 빼고 굽기」를 쓰는 이유** — ⑦은 34장을 새로 합성한다. TTS 는 같은 글도
매번 다르게 읽어서(같은 문장이 3.73 / 3.59 / 3.55초), 듣고 OK 한 소리가 다른
소리로 바뀐다. 장별로 이미 합성해 뒀으면 남은 일은 자막 시각을 다시 잡는
것뿐이다.

그다음 **영상 렌더링을 한 번 더.** 모션은 **완성 mp4 의 오디오를 그대로
복사한다**(`-c:a copy`). 옛 mp4 위에 모션을 얹으면 고친 장만 옛 발음으로 남는다.

---

## 8 · 모션 전체 굽기

좌측 메뉴 **모션** → **전체 굽기**  ·  원본 길이의 1.5~1.8배(20분 → 35~40분)

> 📷 _캡처 자리 — 모션 화면_

글자가 말하는 차례대로 떠오르고 빛이 훑는 판을 다시 굽는다. 값을 바꿔 보고
싶을 때만 **시안 95초**를 먼저 굽는다(2분).

★ 모션 화면의 **1·2번(지정기·zones 불러오기)은 옛 자리**다. 덱에서 하는 것과
같은 일인데, 여기 것은 파일을 통째로 갈아서 덱에서 고친 것을 덮는다.
**3번 굽기만** 쓰면 된다.

끝나면 **유튜브에 올릴 글**을 복사해 올리고, 마지막으로 통째로 들어 본다.

> 📷 _캡처 자리 — 유튜브에 올릴 글_

## 막혔을 때

| 증상 | 왜 · 어떻게 |
|---|---|
| 화면이 통째로 안 뜬다 (`Invalid or unexpected token`) | JS 문법이 깨졌다. 코드 문제다 — 알려 달라 |
| 스토리보드가 안 보인다 | **전체 보기에는 없다.** 장 번호 탭을 눌러 한 장 보기로 |
| 노란 줄도 스토리보드도 없다 | 영상을 아직 안 구웠다. 7번 먼저 |
| 지정기를 눌렀는데 아무 일도 없다 | 1~2분 걸린다. 끝나면 새 창이 열린다 |
| 고친 발음이 안 먹는다 | 그 장 오버라이드에 옛 글이 있다 — 「자막에서 발음 만들기」 |
| 파이썬을 고쳤는데 그대로다 | `run.bat` 에 `--reload` 가 없다. 서버를 껐다 켠다 |
| 화면 코드를 고쳤는데 그대로다 | 브라우저 새로고침(Ctrl+F5). 서버는 안 껐다 켜도 된다 |
| 대본이 짧게 나왔다 | 원고 `data-say` 가 비었다. 1번으로 돌아간다 |
| 자막 시각이 어긋난다 | 음성 길이가 바뀌었다. 「음성 빼고 굽기」 |
| 발음이 씹힌다 | 한 문장에 숫자가 너무 많다. 발음 칸에서 문장을 끊어라 |
